ACCOUNT MODEL

实现说明：当前 ID Token 校验包含 iss / aud / exp 一致性检查，但不校验 JWT 签名；令牌中的 UUID 不直接作为可信身份使用。

04 — DETECTION
V0.1.7 · DOWNLOAD ENGINE

下载引擎，重新设计。

把 PCL2 ModNet / ModLoader 的下载语义迁移到 Rust，统一调度文件、线程与下载来源。

NET MANAGER

由一个管理器统一协调

分片策略

根据文件大小决定是否分片：256 KiB 以下不分片，1 MiB 以下不拆成多段，大文件按片段并发下载。

自适应连接与慢链识别

结合连接平均耗时与失败次数调整超时，并将 Range 不支持、HTTP 状态码、慢链、无数据等情况分类。

全局下载控制

令牌桶控制下载速率，线程上限控制并发；旧调用方仍通过 net.rs 兼容门面接入。

新模块：download.rs · NetManager / NetFile / NetThread / NetSource
05 — DOWNLOAD CORE
V0.1.7 · RESUMABLE DOWNLOAD

下载中断，
不必从头再来。

每个分片完成后都会留下进度记录。重新启动时，只补齐还没完成的部分。

● 已完成分片◇ 待补齐分片

断点信息持久化

.part.meta 记录已完成分片；崩溃、关机或切换镜像源后，可恢复未完成部分。

合并校验更稳

下载完成后执行 verify_and_commit，合并阶段提供最多 3 次重试，并采用递增退避。

download_file_resumable · .part.meta · verify_and_commit
06 — RESUME
V0.1.7 · NETWORK FIX

下载先走直连，
需要时再回退代理。

针对系统代理可能带来的绕行与降速，调整下载请求的网络选择策略。

FIRST · DIRECT

优先直连下载

direct_client() 绕过系统 HTTP_PROXY / HTTPS_PROXY，避免下载流量被不必要地转发。

FALLBACK · PROXY

连接失败才回退

proxy_retry_worthwhile 只在连接级失败、直连确实不可达时，才考虑使用带系统代理的客户端重试。

更新记录指出：此前部分环境下下载速度曾降至约五分之一；新策略避免默认绕行代理，并保留连接失败后的回退能力。
net.rs · direct_client() · proxy_retry_worthwhile
